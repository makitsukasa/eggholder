# 卵ケース

CyberCyclist「Egg Carry Holder V2」の cage と同じ仕組み（ねじれた板ばねリブのかご）を
内側に持ち、SanderWel のような**密閉できる外殻**で包んだ携帯卵ケース。
全パーツをスクリプトで一から生成する（外部の STL は不要）。

## 構成：3種類・4パーツ

| ファイル | 役割 | 枚数 | 外形 | モデル体積 |
|---|---|---|---|---|
| `out/cage_unit.stl` | 内側ケージ（点対称なので上下共通） | **2** | φ57.4 × H30.8 | 4.75 cm³ |
| `out/shell_bottom.stl` | 外殻・下（おねじ） | 1 | φ65.2 × H42.5 | 19.23 cm³ |
| `out/shell_top.stl` | 外殻・上（めねじ） | 1 | φ65.2 × H33.0 | 13.86 cm³ |

**組立：最大外径 φ65.2 × 全高 66.0 mm / モデル体積合計 42.6 cm³**（殻は中実なのでインフィルで調整）
（SanderWel は φ63.8・樹脂 115.9 cm³）

## cage のパラメータ（`scripts/01_make_cage.py` 冒頭）

元の cage を計測して求めた値。内径は元の cage と 0.3mm 以内で一致する。

| 変数 | 値 | 意味 |
|---|---|---|
| `H` | 30.8 | 全高 |
| `DOME_A` / `DOME_B` / `DOME_ZC` | 32.1 / 72.0 / -38.3 | ドーム外面の楕円 r = A·√(1−((z−ZC)/B)²)。傾きが45°を超える先端側は接線円錐 |
| `THICK` | 2.0 | ドームの肉厚（法線方向）。内面は外面の法線オフセット |
| `FLANGE_R` / `FLANGE_H` | 27.5 / 2.0 | リム（つば） |
| `N_RIB` | 6 | 板ばねリブの本数 |
| `TWIST` | 58 | リブの根元→先端のねじれ角 [度] |
| `W_BOT` / `W_TOP` | 8.8 / 5.8 | リブ幅（肉厚中央の水平弧長）。z² で細くなる |
| `GAP_Z0` | 2.6 | リブ間の隙間の下端。ここから半円で丸めてリムにつなぐ |
| `N_LEG` | 2 | 保持脚の本数（180°回転対称を保つため偶数） |
| `LEG_T` / `LEG_GAP` | 1.2 / 0.3 | 脚の肉厚 / リブ外面との隙間。内径は自動で R26.9 |
| `LEG_W` | 5.0 | 脚の幅 |
| `BARB_Z` / `BARB_H` / `BARB_F` | 10.0 / 0.6 / 0.3 | 爪の下端 / 張り出し（上下45°） / 先端の平らな部分 |

リブはドーム面上の (z, 幅, 内外) の格子から直接立体を組み、リムと union している。

### 保持脚（蓋を開けても cage が殻側に残る仕組み）

2枚の cage のリムはどちらも bottom のねじ首の中にあるため、そのままだと蓋を開けても
上の cage は卵の上に残る。そこでリムから縦に**脚を2本**立て、先端の**爪**を殻の**全周の環状溝**に掛ける。

- 脚はリムにしか付いておらず、半径方向にもリブの外面から 0.3mm 離し、角度もリブ間の隙間の中央
  （脚の高さの範囲でリブが通らない角度帯の中央、自動計算）に置く。**リブの支持条件は変わらないので板ばねの剛性は変わらない。**
- 溝は bottom 側にも鏡像で彫るので、cage は**上下同一形状のまま**、それぞれ自分の殻に留まる。
- 溝は全周なので cage の向き合わせは不要。蓋をねじ込むときも cage は溝の中で回るだけ。
- 爪・溝とも45°面なので、強く引けば外れる戻り止めになる（洗浄時に外せる）。
- **卵を入れる前に** cage を殻に押し込んで爪をはめる（脚が内側へ 0.3mm たわむ）。

## 外殻のパラメータ（`scripts/02_build_shell.py` 冒頭）

| 変数 | 値 | 意味 |
|---|---|---|
| `CLEAR` | 1.0 | cage のたわみ代（全周クリアランス） |
| `END_CLEAR` | 1.0 | cage 先端と天面・底面の内面との遊び。cage 先端には φ13.8 の穴があり卵の先が出てくるので、大きい卵で足りなければここだけ広げる（全高は増やした量の2倍伸びる。外形・指数 n は自動で追従） |
| `LEG_CLR` | 0.3 | 保持脚・爪と環状溝の隙間 |
| `WALL` | 1.2 | 殻の肉厚 |
| `SKWALL` | 1.6 | 蓋スカートの肉厚 |
| `MAXSLOPE` | 1.0 | dR/dz の上限＝鉛直から45°。**オーバーハング禁止の肝** |
| `PITCH` | 5.0 | ねじピッチ（1条・フランク45°・台形） |
| `TDEPTH` / `TCLR` | 1.0 / 0.30 | ねじ山深さ / はめあい隙間 |
| `NECK_H` | 9.5 | ねじ首の高さ |
| `THR_TURNS` | 1.1 | おねじの巻き数＝噛み合い **396°** |
| `GRV_TURNS` | 2.1 | めねじ溝の巻き数（後述） |
| `SEAM_GAP` | 0.5 | 締め切った時の蓋スカート下端と bottom の肩の隙間 |
| `END_D` | 22.0 | 天面・底面の径 |
| `EGG_N` / `EGG_B` | 2.91 / 22.05（自動） | 外形の超楕円の指数 / 高さ。上下両方の必要形状を包む最小の指数 |

ねじ：外径 φ61.4 / 谷径 φ59.4、山高2.6・溝高4.4・残り山0.6mm。
シールは首の頂面と蓋の肩が当たる**幅1.2mmの環状面**。

外形（**閉じた状態で z=0 について上下対称**）：
- 合わせ目で縦接線・半径＝スカート外径の超楕円 R=R₀(1−tⁿ)^(1/n) → 45°の接線円錐 → 端面 φ22
- top はめねじ溝の外側に `WALL` 以上の肉が要るため、普通の楕円（n=2）では溝の上端付近で肉が `WALL` に足りない。
  そこで肩を張らせる指数 n を、top（溝・下穴＋`WALL`、空洞＋`WALL`）と bottom（空洞＋`WALL`）の両方を包む最小値に二分法で決めている（n=2.91）。
- 曲線は bottom の肩（z=−0.5）と、それと対称な z=+0.5 から始まる。top のスカート下端 z=0〜0.5 は合わせ目の隙間 `SEAM_GAP` の分の
  垂直な帯（曲線は縦接線なので段は出ない）。

空洞は cage 本体の包絡面＋`CLEAR` と、保持脚の包絡面＋`LEG_CLR`（環状溝）の和。外形とのあいだは中実。
外形と首の内径は本体の空洞だけから決め、溝は中実の肉に彫るだけ（溝部の残り肉厚は最小 2.28mm、`WALL` 以上を assert）。

## 設計上の注意（ハマったところ）

1. **cage のドームを楕円のまま先端まで伸ばすと45°を超える。**
   先端付近で内面が最大68°のオーバーハングになる。外殻と同じく
   接線円錐で置き換えて dR/dz ≤ 1 に抑えている。
2. **クリアランス包絡面は頂点だけから計算してはいけない。**
   平らな面には中間頂点がなく食い込む。
   `subdivide_to_size(max_edge=0.4)` でメッシュを細分化してから計算する。
3. **めねじ溝はおねじより1ピッチ分下に長く伸ばす**（`GRV_TURNS = THR_TURNS + 1.0`）。
   溝がスカート下端まで届いていないと、締め込み途中でおねじが溝の端に衝突する。
   ランアウトのテーパーも溝側には付けない。
4. **ねじ溝を r/z 両方向に一律オフセットするとフランク角が変わる**（45°→58°で
   サポートが必要になった）。45°を保ったまま隙間を取ること。
5. **booleanの結果をSTLに書くと watertight が壊れることがある。**
   大きなboxとのintersectionを最後に一回かけると直る（`clean()`）。
   ただし**最後の座標移動の後**にかけること。

## 生成手順

```
python scripts/01_make_cage.py    # -> out/cage_unit.stl（out/work/cage_body.stl, cage_legs.stl も出す）
python scripts/02_build_shell.py  # -> out/shell_bottom.stl, out/shell_top.stl（cage の包絡面から空洞を作る）
```

検証：

```
python scripts/90_verify.py     # ねじ込み干渉 / 引抜き保持 / cage干渉 / cage保持 / オーバーハング
python scripts/91_overhang.py   # 接地面を除いたオーバーハング面積
```

`PREVIEW_DIR=<dir>` を設定するとプレビューPNGも出力する。
依存：`pip install trimesh manifold3d pillow`

### 現在の検証結果（全てパス）

```
ねじ込み 0->540度 (10点)      : 干渉 0.00 mm3 すべて
真上に引抜き 1.5 / 3.0mm      : 87 / 94 mm3  -> ねじが軸方向を保持
cage上下 x bottom/top (4組)   : 干渉 0.00 mm3
cage を殻から 0.3/0.6/1.0mm 離す: top 0.00 / 0.56 / 1.41 mm3, bottom 0.00 / 0.56 / 1.63 mm3 -> 爪が溝の段に掛かる
オーバーハング(接地面を除く)  : bottom 0.0 mm2 / top 0.0 mm2 / cage 0.0 mm2
3部品すべて watertight・単一ボディ
```

## 印刷

- **bottom**：平らな底を下にして、そのまま。サポート不要。
- **top**：**天面を下にして反転**。スカートが最終層。サポート不要。
- **cage**：リムを下に、2枚。脚も縦に立つのでサポート不要。

接地面は bottom・top とも φ22mm（約380mm²）。ブリム推奨。

はめあいがきつい／緩い場合は `scripts/02_build_shell.py` の `TCLR`（現在0.30）を
調整して `02` から作り直す。
