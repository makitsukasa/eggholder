# 卵ケース

CyberCyclist「Egg Carry Holder V2」の cage と同じ仕組み（ねじれた板ばねリブのかご）を
内側に持ち、SanderWel のような**密閉できる外殻**で包んだ携帯卵ケース。
全パーツをスクリプトで一から生成する（外部の STL は不要）。

## 構成：3種類・4パーツ

| ファイル | 役割 | 枚数 | 外形 | モデル体積 |
|---|---|---|---|---|
| `out/cage_unit.stl` | 内側ケージ（点対称なので上下共通） | **2** | φ58.8 × H26.9 | 5.09 cm³ |
| `out/shell_bottom.stl` | 外殻・下（おねじ） | 1 | φ64.6 × H33.1 | 18.14 cm³ |
| `out/shell_top.stl` | 外殻・上（めねじ） | 1 | φ64.6 × H46.6 | 29.85 cm³ |

**組立：最大外径 φ64.6 × 全高 70.2 mm / モデル体積合計 58.2 cm³**（殻は中実なのでインフィルで調整）
（SanderWel は φ63.8・樹脂 115.9 cm³）

`out/egg_large.stl` / `out/egg_small.stl` は検証用の卵のモデル（印刷しない）。

## 入る卵

実測した2個の卵で確認している（`scripts/03_make_eggs.py`）。

| 卵 | 長さ × 太さ | 推定重さ | リブの先の変位（片側） | 卵の先と天面・底面 |
|---|---|---|---|---|
| 大 `large` | 58.5 × 47.7 | 約75g（LL の上限付近） | +6.4 mm（逃げ代 7.0 以内） | 5.7 / 3.6 mm |
| 小 `small` | 54.5 × 41.3 | 約52g（MS の下限） | +0.6 mm（押し付けが掛かる） | 7.4 / 5.9 mm |

- 卵の形は Hügelschäffer の卵形で近似している。尖り具合 `w` は測っていないので 2.0mm を仮に置いている。
- 変位はリブが高さに比例して伸びるとみなした概算（リブの剛性は計算していない）。
- 大きい卵は細長さ（太さ/長さ）が 0.82 と丸い。旧版の cage はリムのすぐ上で内径が φ47 まで細くなっていて、この胴が当たって入らなかった。

## 仕組み：cage はリムで固定し、先端は浮かせる

リブは先端でつながっていない6本の指で、卵に押されると**円錐の面に垂直に、花が開くように外側へ反る**。
リムを固定し、指の先は浮かせておかないと、ばねとして働かない。そこで次のようにしている。

- 2枚の cage のリムを背中合わせに重ね（合わせ面が z=0）、**bottom の首の頂面（z=−2）と蓋の肩（z=+2）で挟む**。
  卵のばね力はリム→首の頂面・蓋の肩→ねじで受ける。
- cage の先端と天面・底面の内面のあいだは `END_CLEAR`（7.0mm）空いていて、普段は当たらない。
  大きい卵ではリブの先がこの範囲で逃げる。空洞は、先端が逃げてリブが伸びた形も含めて作ってある。
- ドームの内面は「円筒（φ49）→ 45° の円錐」。卵の両端を円錐で受け、太い卵の胴は円筒の部分で逃がす。
  円錐で受けると、卵の中心と円錐の頂点の距離は ≒√(a²+b²)（a, b は長さ・太さの半分）なので、
  長さだけでなく太さの違いもリブの変位で吸収する。
- 小さい卵の締まり具合は、cage の内側の大きさ（`APEX`）だけで決まる。`END_CLEAR` を広げても緩くはならない。
- 大きい卵（変位 6.4mm）では、指の面に垂直な撓みは当たる位置で約 2.9mm。根元のひずみは概算で 1% 前後と、
  PLA の積層方向の限界に近い。割れるようなら PETG で印刷する。
- 蓋の内側の**出っ張り**（3か所）が、上の cage のリム外周の V 溝にはまる。蓋を開けても上の cage は蓋側に残る。
  出っ張りは溝の中で浮いていて、荷重はかからない。はめるとき・外すときは、リムが 0.30mm（`BUMP_H − TCLR`）たわんで乗り越える。

旧版は、保持脚の爪で cage を殻に留め、cage は殻の中を滑って先端が天面に当たったところで止まっていた。
ばねが効かないうえ、脚が折れることもあったため、この構成に変えた。

## cage のパラメータ（`scripts/01_make_cage.py` 冒頭）

リブの本数・ねじれ・幅は元の cage を計測した値。ドームの形は実際の卵に合わせて変えている。

| 変数 | 値 | 意味 |
|---|---|---|
| `IN_R` | 24.5 | ドーム内面の円筒部の内半径（太い卵 φ47.7 の胴を逃がす） |
| `APEX` | 33.8 | 内面の 45° 円錐の頂点の高さ。小さい卵に 0.6mm 押し付けが掛かる位置 |
| `HOLE_R` | 6.9 | 先端の穴の半径。全高 `H` = `APEX` − `HOLE_R` = 26.9 |
| `THICK` | 2.0 | ドームの肉厚（法線方向）。外面は内面の法線オフセット |
| `FLANGE_R` / `FLANGE_H` | 29.4 / 2.0 | リム（つば）。**外径＝殻の首の外径**（02 はリムの外径から首を決める） |
| `RIM_GRV` | 0.5 | リム外周の V 溝の深さ（上下45°、リム厚の中央）。蓋の出っ張りがはまる |
| `N_RIB` | 6 | 板ばねリブの本数 |
| `TWIST` | 58 | リブの根元→先端のねじれ角 [度]。進み方は、ねじれの向きの側の縁の傾き r·dθ/dz がどの高さでも同じ（0.79＝38°）になるように決める |
| `W_BOT` / `W_TOP` | 8.8 / 5.8 | リブ幅（肉厚中央の水平弧長）。z² で細くなる |
| `GAP_Z0` | 2.6 | リブ間の隙間の下端。ここから半円で丸めてリムにつなぐ |

リブはドーム面上の (z, 幅, 内外) の格子から直接立体を組み、リムと union している。
ねじれを z に比例させると、円錐が続く半径の大きいところと、幅の角度が急に広がる先端で、リブの側面が下向き 45° を超える。

## 外殻のパラメータ（`scripts/02_build_shell.py` 冒頭）

| 変数 | 値 | 意味 |
|---|---|---|
| `CLEAR` | 1.0 | cage のたわみ代（全周クリアランス） |
| `END_CLEAR` | 7.0 | cage 先端と天面・底面の内面の間隔＝大きい卵でリブの先が逃げられる量（板ばねのストローク）。全高は増やした量の2倍伸びる |
| `BUMP_N` / `BUMP_H` / `BUMP_W` | 3 / 0.6 / 4.0 | 蓋の内側の出っ張り：数 / 内径からの張り出し / 幅。きつい・緩いときは `BUMP_H` で調整 |
| `WALL` | 1.2 | 殻の肉厚 |
| `SKWALL` | 1.6 | 蓋スカートの肉厚 |
| `MAXSLOPE` | 1.0 | dR/dz の上限＝鉛直から45°。**オーバーハング禁止の肝** |
| `PITCH` | 5.0 | ねじピッチ（1条・フランク45°・台形） |
| `TDEPTH` / `TCLR` | 1.0 / 0.30 | ねじ山深さ / はめあい隙間（リムと蓋の下穴の隙間も同じ） |
| `NECK_H` | 9.5 | ねじ首の高さ（首の頂面 z=−2 から下へ） |
| `THR_TURNS` | 1.1 | おねじの巻き数＝噛み合い **396°** |
| `GRV_TURNS` | 2.1 | めねじ溝の巻き数（後述） |
| `SEAM_GAP` | 0.5 | 締め切った時の蓋スカート下端と bottom の肩の隙間 |
| `END_D` | 24.0 | 天面・底面の径。先端が逃げる分だけ空洞の先が太く、22 では肉厚が足りない |

ねじ：外径 φ60.8 / 谷径 φ58.8、山高2.6・溝高4.4・残り山0.6mm。
首の肉厚（＝首の頂面にリムが載る幅）は 1.82mm、蓋の肩にリムが当たる幅は 1.81mm。
シールは「首の頂面／リム／リム／蓋の肩」の3つの**平らな環状面**。

外形（**閉じた状態で z=0（リムの合わせ面）について上下対称**。合わせ目の隙間 `SEAM_GAP` を除く）：
- |z|≤12 は半径 `SKIRT_R` の**円筒の帯**で、ねじ・リムはこの中に入る。合わせ目は帯の下端近く（bottom の肩 z=−12、蓋スカート下端 z=−11.5）。
- 帯の端からは、縦接線の超楕円 R=R₀(1−tⁿ)^(1/n) → 45°の接線円錐 → 端面φ24。
  指数 n は上下両方の必要形状を包む最小値を二分法で求める（n=2.00、普通の楕円で収まる）。
- 蓋の下穴・めねじ溝＋`WALL` の必要形状はスカート下端（z=−11.5）より上だけで数える。
  下穴を切り抜く余分な長さまで入れると、鏡像が帯の端を越えて上側の肩が絞れなくなる。

## 設計上の注意（ハマったところ）

1. **cage のドーム内面は 45° より寝かせられない。** cage はリムを下にして印刷するので、
   内面の傾きは鉛直から 45° まで（旧版の楕円のドームは先端で 68° になり、接線円錐で置き換えていた）。
   リブの側面も、ねじれの分だけ傾くので 45° を超えないようにする（`TWIST` の進み方）。
2. **クリアランス包絡面は頂点だけから計算してはいけない。**
   平らな面には中間頂点がなく食い込む。
   `subdivide_to_size(max_edge=0.4)` でメッシュを細分化してから計算する。
3. **めねじ溝はおねじより1ピッチ分下に長く伸ばす**（`GRV_TURNS = THR_TURNS + 1.0`）。
   溝がスカート下端まで届いていないと、締め込み途中でおねじが溝の端に衝突する。
   ランアウトのテーパーも溝側には付けない。
4. **ねじ溝を r/z 両方向に一律オフセットするとフランク角が変わる**（45°→58°で
   サポートが必要になった）。45°を保ったまま隙間を取ること。
5. **booleanの結果をSTLに書くと watertight が壊れることがある。**
   大きなboxとのintersectionを最後に一回かけると直る（`clean()`）。
   ただし**最後の座標移動の後**にかけること。
6. **cage を殻の中で浮かせてはいけない。** 先端が天面・底面に当たって止まる構成だと、ばねが効かない。
   また `END_CLEAR` を広げると cage ごと滑り、45°の側面や保持部品に当たる。cage はリムで固定する。

## 生成手順

```
python scripts/01_make_cage.py    # -> out/cage_unit.stl
python scripts/02_build_shell.py  # -> out/shell_bottom.stl, out/shell_top.stl（cage の包絡面から空洞を作る）
python scripts/03_make_eggs.py    # -> out/egg_large.stl, out/egg_small.stl（検証用の卵。卵の寸法は冒頭の EGGS）
```

検証：

```
python scripts/90_verify.py     # ねじ込み干渉 / 引抜き保持 / cage干渉 / 出っ張りの保持 / リムで止まるか / 先端の逃げ / 卵 / オーバーハング
python scripts/91_overhang.py   # 接地面を除いたオーバーハング面積
```

`PREVIEW_DIR=<dir>` を設定するとプレビューPNGも出力する。
依存：`pip install trimesh manifold3d pillow`

## 印刷

- **bottom**：平らな底を下にして、そのまま。サポート不要。
- **top**：**天面を下にして反転**。スカートが最終層。サポート不要。
- **cage**：リムを下に、2枚。サポート不要。

接地面は bottom・top とも φ24mm（約450mm²）。ブリム推奨。

組立：bottom の首に下の cage をリムを上にして載せ、卵を入れる。上の cage を蓋の中に押し込んで出っ張りにはめ、蓋を締める。

ねじのはめあいがきつい／緩い場合は `scripts/02_build_shell.py` の `TCLR`（現在0.30）を
調整して `02` から作り直す。
